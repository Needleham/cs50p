## Final Project Brief
- Project must be implemented in Python 
- Your project must has a main function and three or more additional functions that are accompanied by tests using pytest
    - Main function must be in a file called project.py which should be in the root of the project
    - Your 3 required custom functions other than main must also be in project.py and defined at the same indentation level as main 
    - Test functions must be in a file called test_project.py which should also be in root. Be sure they have the same name as your custom functions appended with test_ 
    - Welcome to implement additional classes and functions as you see fit beyond the minimum requirements 
- Any pip installed libraries that your project requires must be listed, one per line, in requirements.txt
